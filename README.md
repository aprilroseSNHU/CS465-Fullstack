# CS465_FullStack
CS465 - Full Stack Development with MEAN


Frontend Development Comparison
During the full-stack project, various frontend technologies were employed to meet different requirements. Initially, the customer-facing site was built with Express HTML but later transitioned to .hbs views to improve rendering efficiency by avoiding full-page reloads. While HTML provides static, client-facing content, JavaScript added dynamic functionality by pulling data from the MongoDB database. This allowed the page to update dynamically based on user interactions. The project also utilized a single-page application (SPA) framework, which eliminates the need for full-page reloads, offering a smoother, app-like experience for users.

Backend Database Selection
The project used a NoSQL MongoDB database due to its flexibility in adapting schema changes and its scalability for expanding application needs. MongoDB’s non-relational structure facilitated horizontal scaling and quick implementation of new functionality.

JSON and Full-Stack Integration
JSON serves as a bridge between frontend and backend development by providing a standardized data format easily interpreted by JavaScript. It allows data to be stored once in the backend and reused dynamically in the frontend based on user requests, streamlining development and enhancing flexibility.

Code Refactoring and Reusable UI Components
Refactoring improved both functionality and efficiency. For example, consolidating the trip card and trip list components into a unified rendering process streamlined the codebase. Reusable UI components reduced application size, sped up development, and minimized vulnerabilities, provided the components were secure.

API Testing and Security
API testing methods ranged from accessing endpoints directly in the browser to using tools like Postman, which handled security layers such as authentication. HTTP methods like GET, POST, PUT, and DELETE drove the application’s functionality by interacting with the database to retrieve or modify data. Ensuring secure endpoints was critical to prevent unauthorized access or tampering with sensitive information.
